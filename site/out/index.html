03 · The receipts

A plan that can cite its sources.

Your TypeScript, Node.js, PostgreSQL, and REST background already matches the core stack. The main gaps are agent-specific backend capabilities: reliable stateful orchestration, outcome-based evaluation, production observability, safe tool execution, and rigorous automated testing. With eight focused hours per week, build these as connected parts of one production-style agent service rather than as separate technologies.

01

Resilient stateful agent workflow orchestration

All three roles need services that preserve state across multi-step or long-running work and recover correctly from failures. This is the central backend skill separating conventional request-response web services from production agent systems.

Agent evaluation harnesses and success metrics

Production agent teams must measure whether an agent completed the intended task correctly, not merely whether its code executed. You need experience defining success criteria, building repeatable eval cases, and detecting behavioral regressions.

Agent observability, tracing, and production debugging

Agent behavior spans multiple model calls, tools, and state transitions, so ordinary request logs are insufficient. You need traces and structured telemetry that make failures and unexpected decisions diagnosable in production.

04 · The struggle ladder

One honest attempt. One earned rung.

Real attempts earn one rung. Cold asks earn a refusal.

  1. 01

    Socratic question

    One question aimed at the misconception in the learner’s actual attempt.

  2. 02

    Concept pointer

    One exact idea to look up, without handing over the implementation.

  3. 03

    Worked analogy

    The same reasoning pattern, transferred into a different domain.

  4. 04

    Partial scaffold

    Structure, checkpoints, or pseudocode—never the finished solution.

  5. 05

    Defense

    The learner explains the approach and predicts behavior before confirmation.
